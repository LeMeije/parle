# Icon explorations

`0-current.svg` is the SHIPPING icon (also in src-tauri/icons/) — keep it.
The rest are explorations, never wired into the build:

1. **Keycap** — the app as a physical key, thin ink border, cobalt mic. Plays on the name.
2. **Waveform** — dark slate utility tile, thin inner hairline, cobalt bars.
3. **Echo rings** — paper background, thin cobalt border, sound rings radiating from a dot.
4. **Cassette** — the Retro theme as identity; cream, ink outline, orange reels.

To adopt one: `npx tauri icon assets/icon-explorations/<name>.png` (renders all sizes),
then rebuild. Keep the favicon/brand image in src/assets/icon.png in sync.
